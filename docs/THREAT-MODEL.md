# Threat model

Status: approved by the owner on 2026-10-30. The control column describes today's host (`docs/adr/0016-agent-user.md` to `docs/adr/0024-state-over-incident-lists.md`). Row ids stay. A control marked "In redesign" is the current state until the new base is built (`docs/PRODUCT-BRIEF.md`).

This file lists the workflow nodes and threat nodes from two articles and from the owner's grill. It splits them by job: underground or arkan. underground owns the agent user, the gh-broker, and the merge gate. arkan owns the agents: tasks, schedules, memory, budgets, and output.

Scope: one owner, one mac, one macOS user, and omp as the only agent. The repos are public. A private repo reopens U14 (`docs/PRODUCT-BRIEF.md`, user and scope).

Sources:

- A: [How the Claude Code team does code review](https://claude.dev/blog/solving-code-review-at-anthropic/), 2026-10-15, read 2026-10-29.
- B: [Building effective agent automations](https://claude.dev/blog/building-effective-agent-automations/), 2026-10-08, read 2026-10-29.
- G: the owner's grill on the product brief, 2026-10-29, 2026-10-30, and 2026-11-02.
- gh: GitHub's docs on GitHub Apps, read in their source in `github/docs` on the `main` branch, 2026-10-31: [Choosing permissions for a GitHub App](https://docs.github.com/en/apps/creating-github-apps/registering-a-github-app/choosing-permissions-for-a-github-app), [Generating an installation access token for a GitHub App](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/generating-an-installation-access-token-for-a-github-app), and [Managing private keys for GitHub Apps](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/managing-private-keys-for-github-apps).
- omp: the oh-my-pi repo, `main` at `650f3a1`, read 2026-11-02: `docs/auth-broker-gateway.md`, `docs/config-usage.md`, `packages/coding-agent/src/session/agent-session.ts`.

Irreversible: after the harm, no action restores the earlier state. A row is irreversible when its worst consequence is irreversible, for example when it lets a change skip the merge gate. Reversible: a revert, a delete, or a settings change restores the earlier state.

MVP 0.5 holds every irreversible underground row except U14 (accepted risk), U16 (no credential needs it yet), and U27 (deferred), plus U19, U20, and U31, which keep undo and work possible. The rest is MVPF.

The files and paths of the host are in `docs/HOST-STATE.md`. The values are in `host/facts`. The services are in `host/services`.

Status words in the control column: **Handled** means today's control stops the harm. **Accepted** means an ADR or the owner names the harm and accepts it. **Open** means a part is not built or not tested. **In redesign** means the control is a quality step, or a part is due to change.

|U31|An author session moves a ref or writes an object in the owner's repo `.git`.|G|0.5|**Handled.** The agent works in its own clone, never in the owner's checkout. The owner's home is mode 700 (U1). |
|U35|A CI log carries a secret or an instruction into an author session.|B, A|0.5|**Handled.** `gh-broker ci-log` returns only the failed steps of `pull_request` runs whose head commit is the PR head (`failedPullRequestRuns`, `host/gh-broker/protocol.ts`). It refuses when the head has a deployment, so a log of an environment with secrets never leaves GitHub (`handleCiLog`, `host/gh-broker/server.ts`). |U11|A PR weakens its own review, or a merged change weakens later reviews.|A|0.5|**Accepted** (`docs/adr/0011-one-agent-arena.md`). The harm is a bad merge, which onboarding checks 5 and 6 keep reversible (U10, U19). A change to `.github/**` or `CODEOWNERS` stays a hold (`isProtectedPath`, `host/gh-broker/protocol.ts`). |
|U32|One agent role changes state that another role trusts: omp's config, caches, temp files, git refs that a reviewer diffs against.|G|0.5|**Accepted** (`docs/adr/0011-one-agent-arena.md`). |U21|One session damages the code, temp files, or clone of another session, in any repo the agent user works in.|G|MVPF|**Accepted** (`docs/adr/0011-one-agent-arena.md`). Only agent work is lost; the agent redoes it. |
|U37|An agent deletes or rewrites data in its home that the owner cannot rebuild: the session history, `history.db`, unpushed work.|G|0.5|**Handled, with a limit.** Undo, not prevention: the agent must be able to write in its home. A failed run or a last good backup older than 36 hours reaches the owner through the watch (`backup_stale`, `host/bin/ug-watch`; `docs/adr/0023-failures-reach-the-owner.md`). **Limit:** harm to data written after the last run cannot be undone. The backup opens only with its password, so keep a copy outside the mac. |
